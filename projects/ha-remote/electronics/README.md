# Electronics

No custom board. The XIAO ESP32S3 + Wio-SX1262 kit is used as it comes, with
switches, a LiPo cell and a battery divider wired point to point. The wiring table
is on the site's Wiring page (`pages/04-wiring.mdx`); the firmware is in
`../firmware/`.

A small carrier PCB (switch footprints, divider, battery connector) would be the
next step if more than a couple of these get built.
